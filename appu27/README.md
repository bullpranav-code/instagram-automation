# Appu27 robot (separate from the Python project in this repo)
- `appu27/jobs/index.json` lists posts waiting for approval. The Appu27 Autopost Google script reads it every 10 minutes and emails an approval request for each new post.
- Media lives on the `gh-pages` branch and is served publicly through jsDelivr.
- Nothing is posted to Instagram until Boss approves (email button, or "yes" in the Appu27 Queue sheet).
