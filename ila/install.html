Ila + Kili v4.0

How it works

The code is split into small parts so your phone can paste it. Each part goes into its own file in Apps Script. Copy one part → paste → Save → next part.

1 · Ila (5 parts)

  1. Open the Ila project. Delete old files Voice and Kili.gs if they exist (⋮ → Delete).
  2. Part 1 goes into the existing main file: select all → delete → paste.
  3. For parts 2–5: tap + next to Files → Script → name it exactly as shown → delete the sample lines → paste.

Then: Save → Deploy → Manage deployments → ✏️ → Access: Anyone → Version: New version → Deploy.

2 · Kili (3 parts)

  1. Open the Kili project. Part 1 goes into the existing file: select all → delete → paste.
  2. Parts 2–3: + → Script → name as shown → paste.

Then: Save → Deploy → Manage deployments → ✏️ → Version: New version → Deploy.
